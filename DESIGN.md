# Overview

**Creative North Star: "One truth, eight operating worlds."** The portfolio is a cinematic evidence system. Astronomy remains the original cosmic keynote; each opt-in identity changes the material, interface grammar, display voice, and scroll choreography without changing any project fact or route.

**Key Characteristics:**

- Full-bleed pinned scenes driven by scroll position.
- One unmistakable interface metaphor per identity.
- Repository-backed proof and explicit boundaries in both languages.
- Large typographic propositions paired with tactile system geometry.

**The Shared Truth Rule.** A world may reinterpret presentation, never evidence, status, route structure, or language parity.

# Colors

The default world uses near-black space, bright neutral ink, and a blue-violet signal pair. Identity accents are semantic: green for command hardware, gold for storybook warmth, orange for tactical state, red for episodic media, bright green for listening, restrained white for keynote space, and cobalt for connected devices.

**The Native Palette Rule.** Each surface uses one world's palette at a time; project accents remain subordinate proof signals.

**The Evidence Contrast Rule.** Claims and boundaries stay readable on their actual surface and never depend on glow alone.

# Typography

Inter is the durable body and default display system. Identity displays use self-hosted Chakra Petch, Cinzel, Oswald, Archivo, Montserrat, or Sora only inside their corresponding worlds. Arabic body copy uses Cairo; large Arabic statements use Al Rai Media.

**The Proportional Interface Rule.** Monospace is reserved for real code or telemetry; compact interface labels use the world's proportional display voice.

**The Bilingual Scale Rule.** Arabic keeps the same hierarchy but receives its own line height and no forced Latin tracking.

# Layout

Home and project pages begin with full-viewport, sticky narrative stages. The next section adopts a native browsing model: cartridge bay, chapter shelf, mission roster, episode catalog, track queue, product grid, or device ecosystem. Long-form evidence remains centered and readable, while responsive layouts collapse spatial metaphors into a single navigable column below 620px.

**The Native Frame Rule.** Reuse facts and routes, not the astronomy frame or another identity's composition.

**The One Journey Rule.** Every world preserves the same sequence: proposition, project discovery, project mechanism, proof, boundary, and contact.

# Elevation & Depth

Depth comes from world-native perspective, soft offset shadows, layered surfaces, and scroll-linked parallax. Glow is a signal effect rather than the only separation device. Reduced-motion mode keeps every scene visible and removes transform-dependent choreography.

**The Material Depth Rule.** Hardware may hinge, pages may turn, and albums may spin; motion must express the chosen object rather than decorate the viewport.

# Shapes

Astronomy uses orbits and luminous fields. Razer and COD use clipped technical frames. Disney uses page arcs and a castle silhouette. Netflix uses screen rows. Spotify uses circular records and compact tracks. Apple uses immaculate product silhouettes. Samsung uses hinged rectangles and ecosystem orbits.

**The Identity Geometry Rule.** A signature shape belongs to its own world and must not become a global decoration.

# Components

Buttons inherit the active world's accent, outline, radius, and motion character. Project entries keep the same semantic link and bilingual content while their container changes to the world's native unit. The world selector is the only global control that intentionally crosses identities.

### Pinned Narrative Stage

A tall scroll region containing a sticky viewport. JavaScript writes a normalized progress value; CSS turns it into world-specific depth, hinge, page, route, spotlight, waveform, or layer motion.

### Evidence Boundary

Every project surface ends with proof, limitations, tools, and a public source link only when the repository is intentionally public.

# Do's and Don'ts

### Do:

- **Do** verify every figure and status against the corresponding repository.
- **Do** preserve equivalent English and Arabic facts, focus behavior, and routes.
- **Do** make the first viewport unmistakably native to its selected identity.
- **Do** keep mobile and reduced-motion versions complete and navigable.

### Don't:

- **Don't** expose private repository URLs, customer data, credentials, or rights-restricted assets.
- **Don't** reuse the astronomy planet scene outside Astronomy.
- **Don't** change project truth to make a stronger visual claim.
- **Don't** use monospace as a generic technical costume.

أنظمة Windows · NTFS

اقرأ فهرس نظام الملفات، لا كل مجلد.

يفحص Reclaim قرص NTFS مقاسًا بسعة ١٫٨٦ تيرابايت و٢٫٦ مليون ملف خلال ٤–١٢ ثانية عبر قراءة جدول الملفات الرئيسي، ثم يعيد فحص المسار الحقيقي قبل أي حذف.

فكرة النظام

يعرف NTFS مكان كل ملف مسبقًا.

يدفع المسح التقليدي كلفة لكل ملف. يخزّن MFT الأسماء والآباء والأحجام والصفات في فهرس شبه متصل، فيحوّل Reclaim ملايين الاستدعاءات المتفرقة إلى قراءة متسلسلة.

عقد النظام
المدخلمحلل أقراص Windows يقرأ جدول ملفات NTFS الرئيسي ويضع الحذف خلف بوابات أمان واعية بالمسار.

تُعرض السرعة والدقة معًا.

فحص MFT الدافئ: ٣٫٧ ثوانٍ. البارد: ٩–١٢ ثانية. اختلف قياس التنزيلات عن robocopy بنسبة ٠٫٠٠٠١٪ مع توثيق تغيّر الملفات الحية كباقٍ.

حدود الصلاحية

قراءة MFT الخام تتطلب صلاحية مدير. إذا رفضت طبقة التخزين القراءة أو غابت الصلاحية، يصرّح Reclaim بذلك ويعود إلى مسح المجلدات. الحذف الدائم منفصل ويتطلب كتابة DELETE.

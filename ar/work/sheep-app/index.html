١٥ جدولًا علائقيًا

كل حدثٍ مرتبطٌ بجيلٍ محدّد — مع ترحيلٍ آمنٍ غير مُتلِف عند بدء التشغيل. وأرقام الأذن المُعادة بعد بيعٍ أو نفوقٍ لا يمكن أن تُخلِط السجلات القديمة بالجديدة أبدًا.

02

٥٩ تحقّقًا عبر ١٧ مجموعة

حزمة قبولٍ وانحدار — صفر إخفاقات — تحمي نموذج الهوية وكل قاعدة بيانات.

03

مراجعةٌ نقديةٌ للكود

مراجعون مستقلّون أعادوا التحقّق من كل ملاحظة — والتقطوا خطأ فقدان بياناتٍ في تجديد التطعيم قبل إطلاقه.

GitHub Actions مع كل دفعة

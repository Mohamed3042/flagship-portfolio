Transfer, read back, measure.

B2MH is an export–compose–apply–verify–render pipeline that discovers the maps a built MetaHuman actually samples, preserves their import settings, and measures both texture and render layers.

Architecture study

A clean log can still render the wrong face.

Map names, colour spaces, UV layouts, grooms and render lighting can each report success while producing the wrong visual result. The pipeline treats discovery, readback and measurement as separate proof layers.

The pipeline

Discover before writing. Verify after.

Every destructive apply has a stored restore path.

01

Export sampled maps

The engine reveals actual bindings, sizes and import settings.

02

Compose by layer

Tone, detail, normal and guarded apertures follow different rules.

03

Apply and read back

Applied maps are exported again and diffed against what was sent.

04

Measure both layers

Texture joins and lit renders are reported separately.

Measured result

The tool distinguishes byte accuracy from visual accuracy.

On the documented run, the texture-layer head/body seam moved from dE 8.49 to 1.41 while applied-map readback reached a maximum absolute difference of zero.

Lab boundary

This is machine-specific engineering tooling for Unreal 5.8, Blender and a built MetaHuman. The character, working maps and model weights are not in the repository; no character asset is presented as shipped.

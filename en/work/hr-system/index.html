The problem

Keyword sorting hires the wrong person.

Applications piled up across Gmail, WhatsApp and a downloads folder; the same person applied twice; and keyword ranking once put a procurement officer first for an engineering role. The fix: read, don’t keyword-match — at scale.

What I built

It runs whether I’m there or not.

01

Three channels → one tracker

Gmail, WhatsApp and file drops consolidated into a single colour-coded master tracker — one source of truth.

02

Read-verified scoring

Each likely fit is read, not keyword-matched — which corrected at least 3 mis-rankings.

03

A daily cycle that runs itself

08:30 intake, a read-only WhatsApp check every 5h, and a 19:30 archive — it runs whether I’m there or not.

04

Strict rules, enforced

Male-only shortlist for these roles, never message without approval, never invent data.

The privacy brief

Useful memory without exporting a life.

A personal assistant becomes more useful as it remembers more — and more dangerous if that memory leaves the machine. LifeOS keeps retrieval, speech, vision and files local while making every tool action inspectable.

Local capability

Text, speech, vision and files — on one machine.

The system documents offline OCR, Whisper transcription, vision and handwriting support, encrypted backup restore, and hardware-honest model tiers.

Honest boundary

“Learning” means encrypted memory and retrieval, not model retraining. LifeOS is intentionally single-user and local; it does not auto-send messages or depend on cloud AI.

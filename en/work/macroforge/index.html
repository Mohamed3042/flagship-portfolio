A local Windows macro workbench: record input, edit it as readable rows, branch on screen colour and run it from a hotkey.

Full transmission

MacroForge records keyboard and mouse input into a program-counter macro language — delays, loops, variables, text and six colour branches — and binds it to global hotkeys filtered by window. Macros stay on the machine; nothing is uploaded.

Automation should not be a black box.

Full transmission

Repetitive desktop work invites scripts nobody can read. MacroForge keeps each recorded action as an editable row with readable arguments, so an operator can inspect and change a macro before binding it to a hotkey.

The current desktop source and binary are private. v1.0.0 was previously public under MIT, so copies and licence grants made then cannot be revoked. The linked page is a source-free walkthrough, not the application. Windows 10/11 x64 only; applications may reject synthetic input and MacroForge does not try to evade that. No enterprise deployment or user count is claimed. AI-assisted build; Mohamed specified, reviewed and verified it.

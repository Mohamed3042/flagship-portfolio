Document automation · Clean-room demo

Box what changes. Lock what doesn’t.

Quotation Builder is an employer’s internal desktop tool for bilingual quotation letters. This story covers its architecture and a public clean-room simulator: edit fictional details, watch the A4 page update, switch between English and Arabic, and print.

The drafting problem

Retyping the same letter invites drift.

Sales coordinators draft similar bilingual quotations again and again. The tool reuses approved patterns: stable wording stays locked, only the fields that change become inputs, and a catalogue pick never fills the price.

SYSTEM CONTRACT
INPUTBilingual quotation letters from approved patterns — fixed wording locked, prices always entered by a person.

The letter pipeline

Public proof

The simulator is gated like a product.

The public demo passed calculation, EN/AR direction, one-page A4 print and two responsive-viewport gates, and its fail-first runner plants four independent defects that must each turn their gate red. The private production app is released separately for Windows and both Mac architectures.

Privacy boundary

An employer’s internal tool: its source, document templates, signatures, stamps, client records and prices stay private and are not shown. The public page is a deliberately limited simulator with fictional data, not the production application or its document engine. Production installers are unsigned. AI-assisted build; Mohamed specified, reviewed and verified it.

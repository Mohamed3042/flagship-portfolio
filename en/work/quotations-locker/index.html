The threat model

A shared folder has no accountable reader.

The risk was not only unauthorized access; it was copying, bulk pulling and losing the trail. The replacement scopes every query by owner and designs revocation, watermarking and audit integrity into the data path.

  1. 01Checksum the archive

    Every source is hashed, copied, re-hashed and written to a manifest.

  2. 02Scope by owner

    Authorization follows ownership from the database, never URL shape or cookie role.

  3. 03Derive the served copy

    The original Word file is never served; every PDF page identifies its viewer and time.

  4. 04Chain the evidence

    Audit rows are hash-chained, while database triggers block update and delete.

READBACK / VERIFIED OUTPUT

Controls are enforced at the data boundary.

The suite is written from the attacker’s side: cross-owner reads, guessed ids, session tampering, direct admin calls, forged audit rows and bulk access are explicit cases.

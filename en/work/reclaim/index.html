The systems insight

NTFS already knows where every file is.

A directory walk pays per file. The MFT stores names, parents, sizes and attributes in a mostly contiguous index, so Reclaim turns millions of scattered calls into a sequential parse.

  1. 01Discover the MFT

    Raw volume metadata reveals the MFT data runs instead of assuming a layout.

  2. 02Stream and roll up

    Sixteen-megabyte chunks are parsed across cores and child sizes roll to parents.

  3. 03Explain the heavy path

    Chain collapsing avoids listing the same storage through every ancestor.

  4. 04Re-judge before delete

    Guard resolves the absolute path again, blocks protected areas and uses the Recycle Bin by default.

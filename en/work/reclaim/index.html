The systems insight

NTFS already knows where every file is.

A directory walk pays per file. The MFT stores names, parents, sizes and attributes in a mostly contiguous index, so Reclaim turns millions of scattered calls into a sequential parse.

The scan-to-delete loop

Fast discovery, slow authority.

The scanner and deleter have different trust models.

01

Discover the MFT

Raw volume metadata reveals the MFT data runs instead of assuming a layout.

02

Stream and roll up

Sixteen-megabyte chunks are parsed across cores and child sizes roll to parents.

03

Explain the heavy path

Chain collapsing avoids listing the same storage through every ancestor.

04

Re-judge before delete

Guard resolves the absolute path again, blocks protected areas and uses the Recycle Bin by default.

Measured on the build machine

Speed and accuracy are reported together.

Warm MFT scan: 3.7 seconds. Cold: 9–12 seconds. The Downloads comparison differed from robocopy by 0.0001%, with live filesystem churn recorded as the residual.

Privilege boundary

Raw MFT access requires Administrator. If the storage stack rejects raw reads or elevation is absent, Reclaim says so and falls back to a directory walk. Permanent delete is separate and requires typing DELETE.

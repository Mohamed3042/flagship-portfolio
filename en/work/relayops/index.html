The signed edge

Version. Verify. Retry. Run it for real.

The integration surface is tested the way a caller would use it.

01

Version the contract

A versioned API with scoped keys hashed at rest and a hand-authored OpenAPI 3.1 document compared with the router in both directions.

02

Verify what arrives

Inbound webhooks are checked with HMAC-SHA256 over the exact bytes, a timestamp window and an idempotency key.

03

Retry what leaves

A transactional outbox makes five attempts with backoff and jitter, then dead-letters instead of dropping.

04

Run n8n in CI

Three n8n workflows are imported into a real n8n container and executed on every push.

Integration evidence

Every new gate failed before it passed.

The 121-test suite passes on Python 3.9 and 3.14, including a test that fails if the runtime imports anything outside the standard library. Every new gate was shown red on a sabotaged copy before it was shown green.

Honest boundary

Every business record is synthetic and connectors are local adapters. Slack posts to a labelled fixture until a real incoming-webhook URL is configured. Hours-saved figures in the interface are demo estimates from editable inputs, not client outcomes, and the browser UI’s same-origin API is outside the OpenAPI contract. AI-assisted build; Mohamed specified, reviewed and verified it.

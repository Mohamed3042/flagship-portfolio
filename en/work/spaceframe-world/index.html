One structural model, from grid to take-off.

Spaceframe World is a ground-up modernisation of spaceframe engineering software: parametric grids, vaults, domes and canopies, linear truss analysis, section screening, fabrication schedules and DXF/IFC exchange, with an MCP server that exposes the same safe operations to an agent.

The handoff problem

Model, analysis and estimate should not drift apart.

Structural enquiries arrive incomplete, and the model, solver and hand calculations often live apart. The workbench keeps one canonical SI project model, and its estimate records every missing input as an assumption with a range instead of a silent default.

The engineering loop

Generate. Analyse. Screen. Exchange.

Each stage reads the same canonical model.

01

Generate the structure

Double-layer grids, barrel vaults, domes and circular canopies start from parameters.

02

Analyse every combination

Dense LU and sparse PCG truss solvers run an envelope across every load combination.

03

Screen, don’t certify

Axial screening reports its assumptions and blockers without claiming code compliance.

04

Exchange and automate

DXF, IFC 4.3 and a linked AutoCAD bridge report losses; MCP works inside an allowlisted workspace.

Cross-checked

An independent engine agrees.

Five fixtures from 2 to 162 free degrees of freedom go to this solver and to OpenSees from one file and agree to 1e-12 relative. At the v0.4.2-alpha release the repository recorded 325 tests, including a verification suite against closed-form answers.

Engineering boundary

Private pre-release software. The solvers cover small-displacement, linear-elastic, pin-jointed 3D trusses only and are not certified to a design code: results must never be the sole basis for construction and need review by a qualified structural engineer. There is no hosted CI — the gates run locally — and the installers are unsigned. AI-assisted build; Mohamed specified, reviewed and verified it.

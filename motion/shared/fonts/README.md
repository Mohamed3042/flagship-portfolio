# Arabic portfolio type

Added 2026-10-07 following the owner's choice of an available alternative to the
MediaPro specimen. Rakkas supplies expressive Arabic headlines; Noto Naskh Arabic
supplies readable text and controls. These are original upstream font files, not
a reproduction of MediaPro. Fonts are self-hosted, with their SIL Open Font Licenses.

- Rakkas, Zeynep Akay: https://github.com/google/fonts/tree/main/ofl/rakkas
- Noto Naskh Arabic: https://github.com/google/fonts/tree/main/ofl/notonaskharabic

Arabic unicode ranges keep the portfolio's existing Latin lettering. The shared
stylesheet covers live HTML text; lettering already rendered in films or canvas
textures stays part of those artworks. The separately styled Store keeps its font.

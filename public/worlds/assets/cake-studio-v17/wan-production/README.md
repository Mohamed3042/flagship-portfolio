## Accept or retry

Accept a result only when the subject performs the described action, the first and last frames match, the action progresses at 25/50/75 percent, the final frame holds cleanly, and there are no cuts, crossfades, warped hands, material changes, extra objects, text, logos, watermarks, or letterbox bars.

Reject a still zoom or camera-only move. Retry the same job with the original supplied first and last PNGs.
